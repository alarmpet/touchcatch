# UI reference boundary

The four PNG files are byte-identical, user-provided AI-generated concept references. They are not runtime assets or visual goldens. Device chrome, Dynamic Island, status bar, sample copy and sample values are excluded. Rights and theme reviews remain `REVIEW_REQUIRED`, so this registry cannot make a beta build ready.

Runtime UI consumes the frozen theme, screen contract and public wire-derived view models. It does not reproduce reference text, values, fonts, icons or illustrations.
