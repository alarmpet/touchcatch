# Requirement ID migration v8A

Stable IDs are preserved. `DOC-001` through `DOC-067` are retired without reuse because they represented README headings, marketing or genre descriptions, rationale, examples, duplicated score tables, estimates, or descriptive snippets rather than normative contracts. README technology commitments, document inventory links, and the traceability link remain `DOC-068` through `DOC-088`.

No retired ID is renamed. New requirements must receive new IDs; retired IDs must never be recycled.
